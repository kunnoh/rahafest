# RahaFest native frontend

## Installation

```sh
git clone https://github.com/kunnoh/rahafest.git
```

Change directory

```sh
cd rahafest
```

Install dependencies for mobile app

```sh
npm install
```

Install dependencies for chat app

```sh
npm chat-install
```


---


## Run the app

## MOBILE
### Development mode

**Android**

```sh
npm run android
```

**IOS**

```sh
npm run ios
```

**Web**

```sh
npm run web
```

### Lint and test

Lint.

```sh
npm run lint
```

Lint and automatically fix errors.

```sh
npm run lint-fix
```

Test.

```sh
npm run test
```
