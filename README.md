# RahaFest native frontend

## Installation

```sh
git clone 
```

---


## Development mode

**Android**

```sh
npm run android
```

**IOS**

```sh
npm run ios
```

**Web**

```sh
npm run web
```

## Lint and test

Lint

```sh
npm run lint
```

Lint and fix

```sh
npm run lint-fix
```

Test

```sh
npm run test
```
